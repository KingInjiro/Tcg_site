Учет медикаментов

  Программный продукт "Учет медикаментов + ячеечный учет". Этот продукт является дополнением к конфигурации "Бухгалтерский учет для Украины".

"Учет медикаментов + ячеечный учет" позволяет автоматизировать бухгалтерский учет купленных медикаментов, а именно:

  • ведение складского учета в разрезе партий и серий медикаментов;
  • расчет продажных цен от таможенной цены серии;
  • печать комплекта сертификатов при продаже;
  • специальные формы счетов и расходных накладных;
  • дополнительная обработка "Анализ первого события". Служит для оперативного выравнивания налогового учета;
  • дополнительная аналитика "Обороты";
  • отчет "Обороты" с разрезами: период (день, месяц, квартал и т.д.), клиент, товар (ТМЦ), документ и показателями: сумма (приход, расход), доход, процент наценки, остаток ТМЦ, сумма задолжности. Есть возможность выгрузки данных в базу Excel для дополнительного анализа, формирования различных диаграмм и сводных таблиц.
  • введение полноценного ячеечного учета по выбранным местам хранения (складам). Ячеечный учет ведется параллельно складскому. Автоматическое списание с ячеек при проведении расходных складских документов. Учитываются ячейки с браком. Ячеечный учет ведется в разрезах: номенклатура, партия, серия, ячейка. Дополнительные разрезы: поставщик, производитель.
