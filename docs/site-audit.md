# Технічна перевірка сайту TCG

Робота для [PR #18](https://github.com/KingInjiro/Tcg_site/pull/18).
Вихідна версія для порівняння оформлення — коміт
`56373e97ce218fbd390219e299538b70f95fb26c` (після PR #17).
Остаточний результат кожного запуску видно в
[GitHub Actions → Site checks](https://github.com/KingInjiro/Tcg_site/actions/workflows/site-checks.yml).
Публікація на хостинг і злиття PR не входять у цей workflow.

## Що перевіряється

| Частина | Обсяг і межі |
| --- | --- |
| HTML | Усі 51 публічна сторінка готової збірки, Nu HTML Checker |
| Залежності | `npm audit --audit-level=low`; перевірка в CI зупиняється при відомій вразливості |
| Ресурси | UTF-8, standards mode, локальні CSS/фони, 778 розміщень картинок і декодування всіх 246 файлів зображень у Chromium |
| Посилання | 1 077 локальних посилань і 104 фрагменти: ціль справді є в статичному експорті; відсутні файли не замінюються заглушками |
| Завантаження | Наявність цілей у ZIP; сигнатури наявних CHM та ERT. Це не запуск 1С або перегляд кожного документа |
| Конструктор | Імпорт і повторне збереження 51 сторінки; нова сторінка, текст, перетягування, фото, копіювання, чернетка/відновлення, конфлікт змін, експорт і перевірка розпакованого ZIP |
| Пошук | Індекс із збереженого вмісту, нові сторінки, регістр/ё, результат, порожній результат, перезавантаження, скидання, безпечне виведення введеного тексту |
| Форми | Усі чотири сторінки, позитивний сценарій, відмова SMTP, відсутність backend; дані залишаються при помилці |
| Захист обробника | Фіксований одержувач, перевірка origin/токена/полів/розміру, заголовкова ін'єкція, пастка, ліміт повторів, явно дозволений зовнішній origin |
| Приватні налаштування | У статичний експорт записується тільки публічна адреса endpoint, не SMTP-пароль або секрет токена |
| Браузери | Пошук і форми — Chromium, Firefox, WebKit у Linux CI; вузький і широкий екран пошуку. Це не фізичний iPhone чи всі версії Safari |
| Оформлення | Видимі тексти, шрифти, кольори, координати тексту та зображень усіх 51 сторінки при ширині 1440 і 390 px; допуск округлення 1 px |
| Навігація | Оригінальні GIF при наведенні й фокусі клавіатури; старі адреси перенаправляються зі збереженням query та hash |
| Новини та калькулятори | Контрольовані відповіді API: числа, помилки/застарілі курси, повторення запиту, перші десять новин; це не гарантія доступності живих API |
| Кеш | Реєстрація service worker і кешування головної сторінки; не обіцянка повної роботи всього сайту офлайн |
| Доступність | Автоматична структурна перевірка axe-core з тегами WCAG 2.0/2.1 A/AA; зауваження до первісного контрасту й оформлення посилань виводяться окремо |

Окремі тести OAuth використовують імітацію GitHub і не замінюють реальний вхід
після налаштування OAuth App. У тестах форм SMTP також імітується:
жодних листів власнику чи відвідувачам не надсилається.

## Що виправлено без редизайну

- Застарілі FrontPage-обробники форм замінено сучасним серверним endpoint.
  Під наявними підписами `price1C` відновлено відсутні поля та кнопки.
- Пошук використовує власний індекс, що оновлюється при збірці та експорті.
  У початковому наборі індексуються 48 сторінок: технічні `header`, `toc`
  і сам `search` не включені.
- Виправлено невалідне вкладення блоків, структури списків, старі іменовані
  якорі й неправильні переходи до них. Вилучено застарілі недопустимі атрибути.
- Уже наявні назви сторінок стали нативними `h1`; рівні підзаголовків
  впорядковано, порожні заголовки замінено елементами відступу. Спільні класи
  зберігають попередні шрифти й відступи. Nu HTML Checker: 0 помилок і 0 зауважень.
- Видалено окрему резервну Decap-адмінку та її локальний proxy. Основний
  конструктор GrapesJS, його GitHub-вхід, локальне збереження й ZIP-експорт
  залишилися. Старий URL `/admin/legacy.html` переводить до конструктора.
  Сумісні залежності сервера оновлено; `npm audit` 02.10.2026 не знайшов
  відомих вразливостей. Це перевірка бази advisories, не гарантія відсутності
  будь-яких можливих помилок безпеки.
- Таблиці, що служать макетом навколо основного вмісту, не видаються за таблиці
  даних. Додано клавіатурний перехід до основного вмісту, назви полів
  та повідомлення про результат пошуку/відправлення.
- Прибрано виклики недоступного рекламного `/pagead/f.txt`; банер,
  кольори, оригінальні картинки та GIF-навігацію не перемальовано.

Оформлення форми `price1C` неможливо порівняти за координатами зі старою
відсутністю полів: це **єдиний виняток геометрії** в тесті. Бізнес-тексти цієї
форми, як і інших сторінок, порівнюються. Службові повідомлення пошуку, форм,
клавіатурний skip-link і fallback без JavaScript — нові функціональні тексти,
а не нові послуги чи рекламний вміст.

## Що не слід називати «повністю перевірено»

1. **Реальна доставка пошти.** Потрібні SMTP-дані власника і одна перевірка
   отримання після налаштування. Успіх API означає прийняття SMTP-сервером,
   не прочитання чи потрапляння у вхідні. Інструкція є в README.
2. **Повна відповідність WCAG.** Початкові кольори й спосіб оформлення
   посилань залишені на вимогу не змінювати стиль. Зафіксовано 14 конкретних
   успадкованих елементів: 11 випадків `color-contrast` на `1CPrice`, `TStand`,
   головній та три `link-in-text-block` на `serv01`. Кількість зауважень у
   конкретному запуску залежить від браузера й доступних шрифтів; усі три
   посилання `serv01` окремо перевірено також у вихідній версії.
   Точні елементи перелічені в `tests/fixtures/accessibility-legacy.json`,
   результати виводяться в журнал. **Нові** порушення цих самих правил
   блокують тест; глобального вимкнення перевірки контрасту немає. Потрібна також ручна перевірка
   клавіатури, допоміжних технологій і змістовності альтернативних описів.
3. **Відсутні старі архіви.** `Docs/rp*.zip` раніше виявилися збереженими
   сторінками помилки, а не справжніми ZIP. Для відновлення потрібні
   оригінальні файли; HTML-переробка їх не створює.
4. **Чужі сайти й сервіси.** Зовнішні статті, лічильники, реклама, курси
   та новини можуть відмовляти незалежно від коду цього репозиторію.
   HTTP 403/502 під час перевірки не доводить остаточного закриття ресурсу.
   Адреси не підмінено довільними альтернативами.
5. **Повністю новий адаптивний дизайн.** Збережено успадкований макет.
   Порівняння при 390 px перевіряє відсутність регресій, а не доводить,
   що кожна стара таблиця зручна на будь-якому телефоні.

## Як повторити

Потрібні Node.js 24, Java 17+ для HTML Validator та браузери Playwright.
Це залежності перевірок/редактора, а не вимоги до відвідувача чи статичного хостингу.

```sh
npm ci
npm audit --audit-level=low
npx playwright install --with-deps chromium firefox webkit
npm test
npm run test:html
npm run test:content
npm run test:calculators
npm run test:browser
npm run test:functionality
TCG_TEST_BROWSER=firefox npm run test:functionality
TCG_TEST_BROWSER=webkit npm run test:functionality
npm run test:accessibility
TCG_BASELINE_DIR=/path/to/baseline-checkout npm run test:preservation
```

Команди зі змінною перед назвою призначені для sh/bash; у PowerShell задайте
`$env:TCG_TEST_BROWSER = "firefox"` окремо. Не запускайте набори, які створюють
`dist`, одночасно. Еталонне дерево має бути окремою копією: тести його не змінюють.
`TCG_APPEARANCE_REPORT` та `TCG_A11Y_REPORT` дозволяють зберегти деталізовані
JSON-звіти. Секрети не потрібні для жодного автоматичного тесту.
