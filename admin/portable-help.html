Редагувати → створити архів → оновити сайт

Конструктор працює на вашому комп’ютері. GitHub, Vercel та паролі для нього не потрібні. На хостингу розміщуються готові сторінки, картинки та документи.

1. Внесіть зміни

Виберіть сторінку ліворуч. Двічі натисніть на текст для редагування. Для нової сторінки натисніть +; варіант Копія поточної сторінки збереже її оформлення. Нові фото додаються через Вибрати зображення → Завантажити.

Зберегти на комп’ютері записує всі правки у робочу папку. В інтернеті сайт ще не змінюється. Кнопка з логотипом TCG відкриває локальний сайт зі збереженими змінами.

2. Отримайте ZIP

Натисніть Архів для хостингу. Конструктор спочатку збереже всі правки, потім завантажить файл tcg-hosting-ДАТА.zip. Копія також з’явиться у папці exports біля START-EDITOR.cmd. Якщо виникла помилка, архів не буде завантажено: прочитайте повідомлення внизу редактора.

3. Завантажте на хостинг

  1. Увійдіть у панель свого хостингу та зробіть резервну копію чинного сайту.
  2. Відкрийте файловий менеджер і папку, з якої працює ваш домен. Вона може називатися public_html, www, htdocs або інакше. Перевірте прив’язку папки в налаштуваннях домену.
  3. Завантажте ZIP і розпакуйте його вміст у цю папку із заміною однойменних файлів. Сам index.html має лежати у папці домену, поруч із images, themes, derived, Docs та іншими файлами архіву. Папки dist чи Tcg_site-main навколо них бути не повинно.
  4. Якщо хостинг не розпаковує ZIP: розпакуйте його на комп’ютері та завантажте всі отримані файли й папки через файловий менеджер або FTP/SFTP. Збережіть назви, регістр літер і структуру.
  5. Перевірте головну сторінку, меню, змінену й нову сторінки, картинки та документи за адресою свого сайту. Після розпакування видаліть завантажений ZIP із хостингу.

Готовий архів містить папки сторінок: наприклад, contacts/index.html відкривається як /contacts/. Завантажуйте всі папки разом із файлами. Старі адреси .html та .htm перенаправляють на нові.

Кожного разу використовуйте найновіший архів. Не видаляйте сторонні файли хостингу навмання. Якщо головну сторінку перекриває старий index.php або перенаправлення, зверніться до підтримки хостингу щодо стартового файлу index.html.

4. Збережіть робочу папку

Усі наступні редагування робіть у тій самій папці проєкту. Для передачі іншій людині або резервної копії збережіть всю робочу папку разом із прихованою .tcg-editor. Можна пропустити node_modules, dist та exports — вони створюються заново. Не передавайте файл .env із секретами.

Копія чернетки зберігає лише незбережені правки, а ZIP для хостингу містить лише публічний сайт. Жоден із них не замінює повну робочу папку конструктора. Нове завантаження з GitHub не міститиме ваших локальних правок.

Повна інструкція з першого запуску, передачею батькові, усуненням помилок та додатковим режимом GitHub є у файлі README.md у робочій папці та в описі проєкту на GitHub.
