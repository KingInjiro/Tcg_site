Общие требования

Для корректной установки дополнения к конфигурации необходим релиз 7.70.258

конфигурации «Бухгалтерский учет для Украины».

После установки продукта нельзя напрямую устанавливать обновления типовой

конфигурации «Бухгалтерский учет для Украины», так как при таком обновлении по типовой процедуре дополнение к конфигурации будет работать некорректно. Для корректного обновления необходимо получить обновление продукта «Учет налога на рекламу» и установить его согласно процедуре, описанной в разделе «Обновление релиза продукта» настоящего руководства.

Порядок установки

1. Запустите мастер установки (файл reklama.exe) и произведите установку программного

продукта (каталог установки не должен совпадать с каталогом какой-либо информационной базы 1С:Предприятия);

2. Запустите систему «1С:Предприятие» в режиме «Конфигуратор»;

3. Сделайте архивную копию вашей информационной базы;

Дальнейший порядок установки продукта зависит от изменений, внесенных в оригинальный релиз 7.70.258 конфигурации «Бухгалтерский учет для Украины».

Если никаких изменений после установки релиза не вносилось или эти изменения никак не затрагивали объекты, перечисленные в разделе «Перечень содержащихся в продукте

изменений», переходите к пункту 4.

Если такие изменения были, переходите к пункту 11.

4. Вызовите режим «Объединение конфигураций», для этого в меню «Конфигурация»

необходимо выбрать пункт «Объединение конфигураций»;

5. В запросе «Открыть файл конфигурации» выберите файл метаданных «1Cv7.MD» с

подкаталога «MD» из поставки дополнения участка «Учет налога на рекламу»;

6. В окне режима «Объединение конфигураций» необходимо убедиться, что:

- в группе «Приоритет конфигурации» был установлен переключатель

«Загружаемая конфигурация»;

- в группе «Метод объединения» установлен переключатель «Замещать

объекты»;

7. Нажмите кнопку «OK» для объединения конфигураций;

8. После завершения будет открыто окно «Конфигурация», содержащее конфигурацию с

внесенными изменениями;

9. Выполните сохранение конфигурации;

10. Переходите к пункту 18.

11. Вызовите режим «Объединение конфигураций», для этого в меню «Конфигурация»

необходимо выбрать пункт «Объединение конфигураций»;

12. В запросе «Открыть файл конфигурации» выберите файл метаданных «1Cv7.MD» с

подкаталога «MD» из поставки дополнения участка «Учет налога на рекламу»;

13. Уберите отметки с объектов, которые были изменены в релизе 7.70.258 конфигурации

«Бухгалтерский учет для Украины»

14. В окне режима «Объединение конфигураций» необходимо убедиться, что:

- в группе «Приоритет конфигурации» был установлен переключатель

«Загружаемая конфигурация»;

- в группе «Метод объединения» установлен переключатель «Замещать

объекты»;

15. Нажмите кнопку «OK» для объединения конфигураций;

16. Выполните сохранение конфигурации;

17. Перенесите все изменения с поставки продукта «Учет налога на рекламу» в

конфигурацию вашей информационной базы.

Для этого:

Откройте конфигурацию вашей информационной базы и конфигурацию поставки продукта и

переносите изменения для каждого объекта, который не был отмечен в пункте 13 установки.

Общая характеристика

Данный продукт представляет собой дополнение участка «Учет налога на рекламу» к

конфигурации «Бухгалтерский учет для Украины» и позволяет автоматизировать следующие моменты учета:

• расчет сумм налога на рекламу при выписке счетов, расходных накладных, актов,

налоговых накладных;

• отражение сумм налога на рекламу в печатных формах документов;

• выполнение проводок по начислению налога на рекламу (по оплате, по отгрузке, по

первому событию);

• определение валовых доходов/издержек с учетом налога на рекламу;

• учет налога на рекламу при приходовании ТМЦ (счета входящие, приходные

накладные, услуги сторонних поставщиков). Сумма налога на рекламу может

включаться как в валовые издержки организации и себестоимость полученных ТМЦ,

так и уменьшать общую сумму начисленного налога на рекламу;

• построение регламентированных отчетов.

Отчет «Анализ первого события»

Настоящий отчет предназначен для проверки правильности проводок, сформированных документами, которые были введены на основании документов-заказов. Алгоритм его формирования следующий: по всем счетам, по которым ведется аналитика в разрезе клиентов и заказов (в типовой конфигурации такими счетами являются все субсчета счетов 36,61,68, а также счета авансов 371,681) для указанных клиентов выбираются все заказы и введенные на их основании документы. Если суммы предварительной оплаты (отгрузки) в соответствующих реквизитах этих документов и реальные суммы предварительной оплаты или отгрузки по бухгалтерским данным не совпадают, то данные документы вместе со своими документами-основаниями будут включены в настоящий отчет.

В диалоговой форме запроса параметров отчета следует указать Фирму и выбрать в реквизите Клиент тех контрагентов, по которым будет составлен настоящий отчет, если же данный реквизит оставить незаполненным, то отчет будет сформирован по всем клиентам фирмы.

В сформированном отчете есть возможность просмотреть, перепровести любой документ из полученного списка в соответствии с реальными данными о суммах предварительной оплаты (отгрузки). Для этого необходимо поместить указатель мыши на нужный документ дважды щелкнуть левой кнопкой мыши и выбрать соответствующую опцию в контекстно-зависимом меню. В конце отчета имеется полее «Провести все» при двойном щелчке на нем будут перепроведены все документы, показанные в отчете

При перепроведении документа будет также исправлена сумма предварительной оплаты (отгрузки) в соответствующем реквизите его диалоговой формы. С помощью опции Открыть подчиненные заказу можно просмотреть список документов, введенных на основании документа-заказа.
