Обновление регламентированных отчетов выполняется следующим образом:

1. Вложенный файлик сохраните на компьютер.

2. Разархивируйте его (нажатием правой кнопкой мыши по нему и "извлечь в текущую папку" - получится папка с именем, в которой есть файлик в виде красненького колесика.

3. Зайдите в режиме "1С:Предприятие" в Отчеты - Регламентированные отчеты, нажмите кнопочку "загрузить" и укажите путь к этому файлику в виде красненького колесика.

4. Выберите его два раза левой кнопкой мыши. Если спросится "Данная группа отчетов существует. Заменить на новые?" Нажмите "Нет".  Новая группа отчетов появится отдельной строчкой в списке групп регламентированных отчетов.
(при появлении окна, с запросом на подтверждение, нажмите кнопку "Извлеч")
Если в комментариях напишется "ошибка выполнения команды", закройте ее и забудьте о ней (такая ошибка, по идее, всегда пишется).
