Сопровождение 1С

1. БЕСПЛАТНОЕ СОПРОВОЖДЕНИЕ ВСЕХ ЛИЦЕНЗИОННЫХ ПОЛЬЗОВАТЕЛЕЙ ПРОГРАММ 1С

Рекомендуем использовать: опытным пользователям, для получения файлов обновлений и самостоятельного обновления программы; при использовании типовых конфигураций
Краткая информация: Вы можете получить файлы с обновлениями, приехав в любой из пяти офисов нашей компании. Для получения файлов обновлений необходимо предоставить регистрационную анкету и носители информации, на которые будут записаны файлы. Такими носителями могут быть дискеты, ZIP-диск, CD-R/RW или Flash-карта
Регулярность: по мере выхода обновлений
Стоимость: прайс-лист. Запись на дискеты, ZIP-диск, Flash-карту пользователя осуществляется бесплатно, запись на CD-R/RW пользователя и запись на CD-R, предоставленный нашей компанией - платно.
Ограничения: в рамках данного вида сопровождения не проводятся консультации по работе с ПП на рабочем месте пользователя, пользователю требуется самому следить за выходом обновлений, затрачивается время на дорогу и получение файлов, сам процесс обновления часто проводится лицами, не имеющим необходимой квалификации, поэтому возможно возникновение ошибок в работе программы; обновление измененных конфигураций требует высокой квалификации пользователя

2. НАСТРОЙКА И СОПРОВОЖДЕНИЕ ПРОГРАММ 1С СПЕЦИАЛИСТАМИ ОТДЕЛА ВНЕДРЕНИЯ

Рекомендуем использовать: для обслуживания измененных конфигураций; для любых изменений программного продукта; для получения любых услуг по сопровождению ПП (обновления, консультации по работе с ПП на рабочем месте и т.д.)
Краткая информация: в рамках этого вида обслуживания Вы можете получать любые услуги по сопровождению ПП 1С
Регулярность: по мере возникновения необходимости
Стоимость: прайс-лист
Ограничения: пользователю приходится самостоятельно отслеживать выход обновлений программного обеспечения

3. ВАРИАНТЫ СОПРОВОЖДЕНИЯ, ВКЛЮЧАЮЩИЕ ПОДПИСКУ НА ИТС.

ИНФОРМАЦИОННО-ТЕХНОЛОГИЧЕСКОЕ СОПРОВОЖДЕНИЕ (ИТС)

Рекомендуем использовать: пользователям, которым необходимо регулярное обновление ПП 1С (обновление проводит специалист отдела сопровождения); при использовании типовых конфигураций
Краткая информация: В рамках ИТС Вы получите комплекс услуг включающий в себя:
Вариант с одним CD (Технологическая поставка) - ежемесячный выезд к Вам в офис специалиста отдела сопровождения; обновление рабочих баз, установленных на Вашем компьютере; предоставление специальной телефонной линии консультации фирмы "1С"; возможность обновления через Internet и другие услуги, производится доставка диска ИТС - специально созданного продукта для пользователей программ 1С, содержащего методическую поддержку программ и разработки фирмы 1С.
Регулярность: ежемесячно
Стоимость: прайс-лист
Ограничения: в рамках Информационно-Технологического сопровождения не производится обновление изменённого программного обеспечения, пользователь не получает консультаций по работе с программными продуктами на своем рабочем месте

4. АБОНЕНТСКОЕ ОБСЛУЖИВАНИЕ ПРОГРАММНЫХ ПРОДУКТОВ 1С

Тарифные планы: "ЭКОНОМИЧНЫЙ" (обслуживание типовых конфигураций) - один выезд в месяц, два часа работы специалиста, "УНИВЕРСАЛЬНЫЙ" (обслуживание измененных конфигураций) - один выезд в месяц, два часа работы специалиста, "КЛАССИЧЕСКИЙ" (обслуживание измененных конфигураций) - до двух выездов в месяц, четыре часа работы специалиста.
Рекомендуем использовать: пользователям, которым необходимо регулярно получать услуги по сопровождению ПП 1С, включая сопровождение измененных конфигураций; для повышения надежности работы ПП 1С
Краткая информация: регулярное оказание услуг, обеспечивающих безотказную работу ПП 1С и поддержание их в актуальном состоянии. В число услуг входят обновления типовых ПП, консультации по работе с ПП на рабочем месте пользователя. В рамках тарифов для нетиповых конфигураций - сопровождение измененных конфигураций и настройка (изменение) ПП. При каждом выезде специалиста, пользователь получает именно те услуги, которые необходимы ему в данный момент
Регулярность: ежемесячно или чаще
Стоимость: прайс-лист
Ограничения: ограничения отсутствую
